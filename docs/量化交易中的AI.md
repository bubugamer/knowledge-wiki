> 量化交易的 AI 核心不是"用最先进的模型"，而是在高噪声、非平稳、强博弈的市场中找到稳定的统计优势——数据质量和工程体系比模型架构更决定收益。

## 定义

量化交易（Quantitative Trading）用数学模型和算法代替人工判断进行交易决策。AI/ML 在其中的角色是从历史数据中提取可预测未来收益的信号（alpha）、优化执行和管理风险。

## 学习范式选择

| 策略类型 | 主要范式 | 原因 |
|---|---|---|
| 预测型（alpha 信号挖掘） | Supervised Learning | 有明确标签：未来 N 期收益/涨跌方向 |
| 执行优化（下单拆单） | Reinforcement Learning | 优化长期目标（滑点最小化），无单步标签 |
| 做市 / 高频 | RL + Online Learning | 需要实时适应市场微结构变化 |
| 组合优化（仓位管理） | RL | 序列决策，奖励延迟 |
| 另类数据挖掘（新闻、财报） | Self-supervised → Supervised | 先用 SSL 做文本表征，再 fine-tune 做情感/事件分类 |

**生产环境最常见的是 Supervised Learning**——绝大多数量化团队在做"给定特征，预测未来收益"。RL 学术上热但工程落地难（reward 稀疏、环境非平稳、过拟合严重、市场模拟器天然无法真实还原 market impact）。

## 模型架构

| 架构 | 用途 | 地位 |
|---|---|---|
| LightGBM / XGBoost | 横截面 alpha、因子非线性组合 | **当前生产主力**，A 股量化绝对主流 |
| MLP | 因子组合 | 树模型的补充 |
| LSTM / GRU | 时序建模（日内/日间序列模式） | 广泛使用 |
| 1D CNN | 局部时间模式提取（tick、盘口） | 高频场景有人用 |
| 2D CNN | K 线/订单簿转图像识别形态 | 2017–2021 热点，已证明易过拟合，非主流 |
| Transformer | 长序列、跨资产注意力 | 在尝试中，尚未形成压倒性共识 |
| GNN | 关联资产、产业链传导 | 股票间关系建模 |

### 为什么树模型长期占主导

- 金融数据量相对小（几十年 × 几千只股票），不够 feed 大型神经网络
- 噪声极强，深度学习容易拟合噪声
- 树模型对小数据、脏数据、非线性关系适应力强
- 可解释性好，便于风控审计
- 训练稳定、迭代快

### 深度学习的位置

头部量化机构（Citadel、Two Sigma、幻方、九坤）基本都用了深度学习，但它和树模型是**并联互补**关系，不是替代。深度学习不是做量化的必要条件，但在中高频和另类数据场景更有优势。

## 训练流水线（以 alpha 预测为例）

```
1. 数据准备
   ├── 行情数据（OHLCV、tick）
   ├── 基本面数据（财报、分析师）
   ├── 另类数据（新闻、卫星、供应链）
   └── 清洗 + 对齐 + 去极值 + 中性化

2. 特征工程（alpha 因子库）
   ├── 量价因子（动量、波动率、流动性）
   ├── 基本面因子（估值、成长、质量）
   ├── 另类因子（情感、事件、资金流）
   └── 因子标准化 + 去行业/市值暴露

3. 标签构造
   └── 未来 N 期收益（rank / 分桶 / 回归目标）

4. 训练
   ├── 滚动训练（rolling window / expanding window）
   ├── 模型：GBDT / MLP / LSTM / Transformer
   ├── 损失：MSE / IC loss / 排序损失
   └── 严格时间切割，禁止未来信息泄露

5. 评估
   ├── IC / Rank IC / ICIR
   ├── 分层回测（多空组合净值）
   └── 换手率、最大回撤、Sharpe

6. 组合优化
   └── 风控约束下的仓位分配（优化器或 RL）

7. 实盘
   ├── 执行（拆单算法 / TWAP / VWAP）
   ├── 在线监控 + 衰减检测
   └── 定期重训（weekly / monthly）
```

## 与 LLM 训练的关键区别

| 维度 | LLM | 量化 |
|---|---|---|
| 数据规模 | TB 级文本 | 相对小 |
| 核心挑战 | scale + alignment | **过拟合 + 非平稳性** |
| 训练频率 | 一次预训练 | 滚动重训（周/月级） |
| 评估标准 | benchmark 准确率 | 实盘 PnL |
| 最大敌人 | 幻觉 | 未来信息泄露 + 过拟合 |
| 模型生命周期 | 年级别 | alpha 持续衰减，需要不断迭代 |

## 核心特性

- **信噪比极低**：金融数据的可预测成分远小于噪声，模型"不够强"不是瓶颈，"过拟合"才是
- **非平稳博弈环境**：你的 alpha 一旦被市场学到就会衰减，持续重训 + 快速迭代比训一个大模型更重要
- **工程决定论**：数据质量、交易成本、延迟控制、风控体系的边际收益通常大于换一个更先进的模型
- **因子模型仍是底座**：即使用了 ML，底层逻辑仍然是多因子框架——ML 的角色是做更好的因子组合和非线性映射

## 常见误解

| 误解 | 实际 |
|---|---|
| "用最先进的 AI 就能赚钱" | 模型先进度和收益没有单调关系；数据和工程更重要 |
| "CNN 看 K 线图就是量化 AI" | CNN 是阶段性热点，已证明在金融中易过拟合，非主流 |
| "RL 自动炒股" | RL 在执行优化有用，但用于选股极度容易过拟合历史 |
| "深度学习取代了传统量化" | 头部机构是树模型 + 深度学习并联，而非替代 |
