> "Agent" 不是新词——从图灵开始就是 AI 的目标。读文献时看到 Agent，要分清楚指哪一代。本页给出三代的最小定义与区分点。

## 三个时代

| 阶段               | 时间          | 代表                           | 核心机制                 | 泛化天花板           |
| ---------------- | ----------- | ---------------------------- | -------------------- | --------------- |
| **符号主义 / GOFAI** | 1960s–1980s | 专家系统、规则推理证明器                 | 手写人类推理规则             | 规则永远写不完；只在本领域管用 |
| **深度强化学习**       | 2013–2020   | DQN、AlphaGo、OpenAI Dota Five | 虚拟环境无限重玩 + reward 优化 | 学了围棋下不了象棋       |
| **大语言模型 + 推理**   | 2022–       | ReAct、o 系列、Operator、Cursor   | 语言先验提供可迁移的"如何思考"     | 目前仍在探索中         |

## 为什么这代能泛化

前两代学到的都是"对特定环境/游戏的理解"——不可迁移。
这一代学到的是"**如何用语言去思考**"——这种技能在不同环境间可迁移。

这是为什么 O 系列只在数学上做 RL，创意写作也能变强——参见 [[推理训练-CoT]]。

## 两条线的进化：方法 + 环境

这代 Agent 的突破常被忽略的一点：**方法和环境同步进化**。

| 方法线 | 环境线 |
|---|---|
| 用语言模型 + 推理（如 [[REACT-推理与行动架构]]） | 从游戏 → coding → 互联网 → 真实数字环境 |

环境从"虚拟可无限自玩"扩展到"真实数字世界"，才是这代 Agent 能产生经济价值的关键。

## 两种"Agent"的术语混用

术语"Agent"今天至少指两件事，读文献时要区分：

| 层面 | 含义 |
|---|---|
| **算法层的 Agent** | 新算法范式（自主学习、内生奖励），对应 [[OpenAI五级智能分类]] 的 L3 |
| **应用层的 Agent** | 市面产品（LangChain / function-call pipeline），本质仍是 L2 Reasoner 的应用 |

两者有代际差异，详见 [[OpenAI五级智能分类]]。
