> **自主学习 / 在线学习** = 下一代训练范式的统称，强调模型**从自然环境中持续自我更新**，而不是训练完就停。张祥雨预测两年内出现突破，是真正进入 L3 Agent 时代的必要条件。

## 与当前 Rubix RL 的区别

| 维度 | 人类 / 目标状态 | 当前 Rubix RL |
|---|---|---|
| 环境 | 自己搭、自己找 | 工程师逐项目手搭 Docker |
| 反馈形式 | 自然语言、多维度 | 标量奖励 |
| 驱动力 | 自驱（内生奖励） | 外部 reward model |
| 学习时机 | 持续终身 | 训练完即停止 |

前一代的三条瓶颈见 [[RLHF-vs-DPO]] 的"局限视角"部分。

## 三个核心技术挑战

### 1. 从自然语言反馈中学习

老师点评："第二段修辞过度，第三段衔接差"——当前 RL 把这些压缩成一个标量 reward，丢失所有维度信息。
**真正要解决**：让模型直接从多维自然语言反馈中定向更新权重。业界尚无好方案。

### 2. 内生奖励（Intrinsic Reward）

> "评价不应该是个外界……我们缺少一个真正的内生驱动。"（张祥雨）

姚顺雨从认知科学给了具体原型——**婴儿**：
- **好奇心** — 探索新刺激
- **掌控感** — 看到自己行动改变世界
- **安全感** — 维持稳态

### 3. 物理 vs 文字游戏的 reward 鸿沟

内生 reward 在不同模态的实现难度差异巨大：

| 场景 | 内生 reward 设计 |
|---|---|
| 物理 / 视觉 Agent | 已有方法（世界模型、好奇心驱动探索、Forward Model 误差） |
| 文字 / 语言 Agent | **几乎空白** |

这是当前自主学习最前沿、最未解的子问题。

### 4. 无限长上下文建模

真实环境是无限长动态序列。自主学习必须能处理这种输入流——与 [[LongContext与分层记忆]] 的分层记忆方案紧密相关。

## 与"世界模型"（LeCun / 李飞飞）的关系

两条路线都瞄准自主学习：

| 路线 | 思路 | 代表 |
|---|---|---|
| 生成式 | 通过生成获得最强自监督信号 | 主流多模态 |
| 非生成式世界模型 | 脑中"想象"未来，不必实际生成 | LeCun / 李飞飞 |

张祥雨判断**殊途同归**。

## 时间预测

<!-- confidence: 预测 | 张祥雨 2025-06、姚顺雨 2025-09 访谈 -->

两位专家独立得出相似判断：**两年以内有突破**。姚顺雨对实现形式持开放态度：

> "也许是改变权重，也许是基于语言的长期记忆，也许是基于 embedding 的长期记忆——具体方式不确定，但它会自我提升。"

**未来核验清单**（到 2027-06 回看）：
- [ ] 是否有模型公开演示"从自然语言反馈直接定向更新权重"的能力？
- [ ] 是否有成熟的"内生奖励"设计出现在主流训练范式？
- [ ] 企业端是否出现"在我们公司内持续学习 N 个月的 agent"产品形态？

## 容易混淆：不是"现在的 Agent 应用"

市面上的 Agent（LangChain、function-call pipeline）本质仍是 L2 Reasoner 的应用——**预编排 pipeline，训练完即停**。真正的自主学习 Agent 能自己找目标、自己形成价值判断、边用边进步。详见 [[OpenAI五级智能分类]]。
