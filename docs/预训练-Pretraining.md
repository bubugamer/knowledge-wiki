> 预训练通过海量文本自监督学习，构建模型的"认知空间上限"；其间有两项决策一旦定下就不可逆，企业通常不亲自做，而是从开源社区选型。

## 核心目标：构建语言的统计模型

通过**自监督学习（SSL）**，典型形式是**因果语言模型（CLM）**——根据前面的词预测下一个词。学成的东西：

- 词与词的统计关系
- 句法结构与语义关联
- 世界范围内的"弱事实共现"

## 不可逆的两项设计决策

### 1. Tokenizer（分词器）

- **是什么**：把文本切成 Token、建立 Token ↔ ID 映射的组件。
- **为什么不可逆**：词表大小（`vocab_size`）决定 Embedding 层尺寸，与权重强绑定。一旦预训练完成，更改 Tokenizer 等于让所有权重失效。
- **工程意义**：它是模型的"眼睛"，决定了模型如何切割世界。

### 2. 模型架构（Config）

- **是什么**：定义骨架的元数据——层数、头数、隐藏层大小等。
- **为什么不可逆**：`config.json` 决定了所有权重矩阵的形状。改核心 Config 等于从零做一个新模型。

### 为什么这两者"不可训练"

它们**不参与损失函数的优化，也不在计算图中**，因此根本不存在梯度来源。它们是模型诞生前的"蓝图"，不是训练产物。

## 企业实践：如何选一个"合法起点模型"

企业不从零预训练，而是从 Hugging Face 等社区选择**起点模型（Starting Checkpoint）**。决策要点：

1. **技术栈匹配**：模型架构是否与现有技术栈兼容。
2. **能力基线**：通用 Benchmark 表现是否满足底线。
3. **法律与合规（生死线）**：仔细审查 License——
   - 是否允许商用？
   - 是否允许分发衍生模型？
   - Apache-2.0 较宽松；其他 License 可能有诸多限制。
